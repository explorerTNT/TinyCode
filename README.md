# tiny-code

**Лёгкий локальный AI-агент для вайбкодинга, который заработает на любом устройстве.**

Запускается на любой машине с CPU (достаточно 8GB RAM и Python 3.8+). Работает через LM Studio с любой open-source моделью (2B–8B параметров). Никаких облачных API, никаких GPU-ферм.

## Возможности

- **7 инструментов**: читать, писать, редактировать файлы, искать код, выполнять shell-команды, задавать вопросы
- **Streaming**: ответ модели выводится по мере генерации
- **Авто-контекст**: умная обрезка истории при длинных сессиях
- **Пермишены**: auto / ask / deny — контроль над bash и записью файлов
- **Бенчмарк**: встроенный замер производительности модели
- **Работа без GPU**: AVX2 / CPU-бэкенд, 4–12 tok/s на современных CPU

## Быстрый старт

```powershell
# 1. Установи LM Studio, скачай модель (например, Qwen 2.5-3B), запусти сервер на 127.0.0.1:1234

# 2. Клонируй и запусти
git clone https://github.com/dvinogradov/tiny-code
cd tiny-code
.venv\Scripts\python agent.py "напиши hello world на Python"

# Или через скрипт (автосоздаёт venv)
.\run.ps1 "открой README.md и покажи содержимое"
```

## Использование

```powershell
# Интерактивный режим
python agent.py

# Одиночный запрос
python agent.py "найди все функции, которые работают с БД"

# С параметрами
python agent.py --workspace C:\project --permission auto "refactor main.py"
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `--model` | Имя модели (по умолчанию из config.py) |
| `--workspace` | Рабочая директория |
| `--permission auto\|ask\|deny` | Режим разрешений |

### Переменные окружения

- `LMSTUDIO_HOST` — хост LM Studio (по умолч. `127.0.0.1`)
- `LMSTUDIO_PORT` — порт (по умолч. `1234`)
- `TINY_CODE_MODEL` — модель
- `TINY_CODE_PERMISSION` — режим разрешений
- `TINY_CODE_MAX_ROUNDS` — лимит раундов (по умолч. `50`)
- `TINY_CODE_TEMPERATURE` — температура (по умолч. `0.6`)
- `TINY_CODE_ASK_USER` — авто-ответ на ask_user (для тестов)

## Бенчмарк

```powershell
python benchmark.py
# или быстро:
python benchmark.py --quick
```

Замеряет: скорость генерации, время ответа, точность выполнения задач.

## Требования

- Python 3.8+
- LM Studio (любая версия, запущенный сервер)
- 8GB RAM (рекомендуется 16GB)
- Модель: любая с поддержкой function calling (Qwen 2.5, Gemma, Mistral, Llama 3)
- Windows / macOS / Linux

## Философия

tiny-code — это opencode для бедных. Маленькая модель, работающая локально без GPU, которая умеет:
- читать и писать код
- искать по проекту
- выполнять команды
- генерировать осмысленные изменения

Идеально для вайбкодинга в поезде, в кафе или на стареньком ноутбуке, когда нет доступа к облачным LLM.

## Структура

```
tiny-code/
  agent.py          # главный цикл агента
  config.py         # конфигурация
  system_prompt.py  # промпт для модели
  permissions.py    # контроль разрешений
  benchmark.py      # бенчмарк
  run.ps1           # скрипт запуска
  tools/
    __init__.py     # регистрация тулов
    read.py         # чтение файлов (rtk + fallback)
    write.py        # запись файлов
    edit.py         # редактирование файлов
    grep.py         # поиск по содержимому
    glob.py         # поиск по имени
    bash.py         # shell-команды
    ask_user.py     # вопросы пользователю
```
